# Замеры в браузере

Проверки, по которым принимались решения правки 07 (полоса под шапкой,
направление движения, шторка, стык). Живут здесь, а не в `.gitignore`:
следующая правка шторки без `contrast-live.mjs` начнётся с нуля.

Требуют playwright, который **не** входит в зависимости сборки — театру он не
нужен, а `npm ci` должен оставаться лёгким:

```
npm i -D playwright
npm run build
npm run qa:rest
```

Снимки складываются в `.build/qa/<проверка>/`.

## Что чем меряется

| Команда | Файл | Что проверяет | Порог |
|---|---|---|---|
| `npm run qa:chapter` | `chapter-top.mjs` | верх вьюпорта в состоянии главы: нет ли сплошной полосы поверх кадра | ровных строк сверху — **0** (СКО яркости < 0,0008) |
| `npm run qa:rest` | `rest.mjs` | покой на остановке не зависит от того, с какой стороны приехали | попарный диф **≤ 1 %** пикселей |
| `npm run qa:contrast` | `contrast-live.mjs` | контраст четырёх строк подписи на самом светлом пикселе под ними | **≥ 4,5 : 1** каждая клетка |
| `npm run qa:seam` | `seam.mjs` | стык последнего кадра с текстовой частью | ступень **≤ 2,0** уровня sRGB; растяжка **≥ 25 %** высоты кадра |
| `npm run qa:fit` | `fit-frame.mjs` | подбор `scrimText` для кадров, не берущих порог | инструмент, не проверка; целится в 4,60 — с запасом к приёмочным 4,5 |
| — | `band.mjs` | профиль строк готового png: где кончается заливка и где резкие горизонтали | — |

`harness.mjs` — общая обвязка: сервер над `dist/`, запуск браузера, переход к
главе, выход из пролёта, формулы WCAG. Делится намеренно: расхождение в том,
как проверки поднимают страницу или считают яркость, означало бы, что их числа
нельзя класть в одну таблицу.

## Отношение к гейтам `npm run check`

`npm run check` браузера не требует и потому роняет сборку сам:

* `check-scrim.mjs` — профиль затемнения, плотность поля и пик под подписью;
* `check-contrast-photos.mjs` — тот же контраст, что и `qa:contrast`, но
  считается статически: по оригиналам, профилю затемнения и геометрии показа
  (cover, кадрирование слота, масштаб камеры). Числа двух проверок обязаны
  сходиться. Расхождение означает, что геометрия в статическом гейте разошлась
  с боевой, — чинить надо гейт, а не порог;
* `check-topbar-strip.mjs` — светлая полоса под шапкой на самих кадрах;
* `check-flight.mjs`, `check-transfer.mjs` — кривая пролёта и вес.

Проверки из этой папки — вторая линия: они видят готовый кадр со всеми слоями
и ловят то, чего статика по построению не видит (порядок наложения, растр
композитора, реальные ступени градиента).

## Переменные окружения

* `VIEWS=390x844,1280x800` — какие окна мерить; по умолчанию все пять
  (390, 768, 1280, 1907×922, 1920×1080).
* `STOPS=0,1,2` — какие остановки брать в `qa:rest`.
* `CHAPTER=3` — на какой главе мерить верх в `qa:chapter`.
* `TARGET=4.7` — цель подбора в `qa:fit`.
* `PLAYWRIGHT_CHROMIUM=/путь/к/chrome` — если браузер стоит отдельно от
  playwright.
