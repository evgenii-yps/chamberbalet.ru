# Оригиналы

Содержимое этой папки в git не коммитим — только требования к исходникам.
Файлы кладутся сюда, дальше их забирают скрипты из `scripts/`.

## `photo/`

Именование строго по порядку показа, имена берутся из `src/content.js`
(поле `photo`), расширение любое из `.jpg .jpeg .png .tif .tiff .webp .avif`:

```
01-hero-interior.jpg     08-nutcracker.jpg
02-format-duet.jpg       09-nutcracker-child.jpg
03-hall-wide.jpg         10-enfilade.jpg
04-venue-empty.jpg       11-kirche.jpg
05-candle-arc.jpg        12-company.jpg
06-candle-close.jpg      13-tutu.jpg          ← вертикальный
07-backdrop.jpg          14-evening.jpg
```

Требования:

* минимум **2560 px** по длинной стороне, целевое **3200 px**;
* без предварительного сжатия, без ресайза, без вотермарков;
* горизонтальные, кроме помеченных в `content.js` как `orientation: 'portrait'`;
* цветовой профиль любой — сборка принудительно приводит к sRGB.

Оригинал меньше 2000 px не роняет сборку, но печатает предупреждение с именем
файла и фактическим размером.

Кадр показывается вплоть до масштаба 2,6 — то, что «выглядит достаточно
крупным» на глаз, почти наверняка недостаточно. Отсюда 3200 px.

## `video/`

Один файл `hero.<ext>` (`.mov .mp4 .mkv .avi .webm .m4v`).

* без звука;
* 6–12 секунд;
* первый и последний кадр совпадают — иначе петля будет дёргаться;
* горизонтальный, от 1920 × 1080;
* сюжет спокойный: поверх лежит заголовок.

Ролика может не быть. Тогда сборка печатает «видео не найдено, собираю без
него», а первый экран живёт на фотографии `01-hero-interior`.

## `fonts/`

Необязательно. Если сюда положить оригиналы `.ttf`/`.otf`, они пойдут в
настоящий субсеттинг через `subset-font`:

```
CormorantGaramond-400.ttf   CormorantGaramond-600.ttf
Manrope-400.ttf             Manrope-500.ttf
```

Если папка пуста, шрифты берутся из пакетов `@fontsource/*`, которые уже стоят
в `devDependencies`. Внешних запросов к шрифтовым сервисам нет ни в том, ни в
другом случае.

**Курсив Cormorant Garamond не подключать ни при каких обстоятельствах:** он
переопределяет кириллицу и портит русский текст.
