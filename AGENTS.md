# Codex operating instructions — chamberbalet.ru

This folder contains a controlled sequence of engineering assignments. **Only the stage explicitly selected by the human owner is active.** When receiving the entire ZIP without an additional stage approval, active stage is **00**.

1. Read `START_HERE_CODEX.md`, `PROJECT_CONTRACT.md`, the active `TASKS/` file and current Notion page before touching source code.
2. Communicate with owner in Russian. Write engineering specs, code, test evidence and stage reports in English unless otherwise required for the site content.
3. Keep an explicit source and verification trail; separate observed facts from assumptions, blocked items and suggestions.
4. Preserve the original Sites prototype as creative truth and GitHub as code truth. Neither a screenshot nor the standalone shortened v0.19 file proves parity.
5. Never advance beyond the active stage; never change the production website or main without separate authorization. Stage 00 = docs only.
6. The owner manually deploys a ZIP to REG.RU. All later release instructions must be clear enough for a nontechnical person and must include recovery steps.
7. Record durable state in Notion and code/docs in a feature branch on GitHub. Include full plan and transition gates in every stage report.
8. Never claim success if the corresponding source, file, test, route or production check was not actually inspected.
