1. Open the original Sites project in the authenticated editor (the live URL is not necessarily the editor). Request/export the complete deployable source or repository, including route files, CSS, JS, data, images, logos, font files, videos and approved download documents.

3. Check that homepage, `people.html`, performance detail pages, venues page, event/tour archive and all actual routes are represented. Verify counts and media against live Site.
4. Keep raw export private pending rights audit. Do not commit unapproved portrait/video assets to a public GitHub repository. Use an approved private storage/secure handoff.
5. Codex may use authorized editor/browser access to inspect the original. If exports are unavailable, label G0 BLOCKED and tell the owner the *specific* missing export/access step. Don't build from partial v0.19.
