# Афиша и продажа билетов — прототип 0.1

Три статических экрана, собранные по `ТЗ-claude-code.md` из пакета дизайн-системы
«Камерный театр балета». Ни сборщика, ни npm, ни фреймворка: откройте
`index.html` двойным щелчком.

```
index.html    афиша
event.html    страница вечера — event.html?id=chopiniana-2026-11-14
system.html   витрина дизайн-системы: токены, компоненты, состояния
```

CSS подключается строго в порядке `tokens.css` → `base.css` → `components.css`.
Данные — `data/events.json`, редактируется руками. Все значения в нём заглушечные.

Что сделано, что проверено, что осталось незакрытым — в [`ОТЧЁТ.md`](ОТЧЁТ.md).
Скриншоты обеих тем на трёх ширинах — в [`скриншоты/`](скриншоты/).

Ничего не задеплоено: решение о production принимается после просмотра прототипа.
