# chamberbalet.ru

Главная страница «Театр {НЕ} Камерного балета» с переключателем масштаба
(«Весь театр» / «Без {НЕ}» — камерный / «С {НЕ}» — большая сцена).
Задание — ТЗ v2 от 29.10.2026; тексты перенесены побуквенно из прототипа
«прототип-главная-v2» и лежат в [`src/content.js`](src/content.js), больше нигде.

> `SPEC.md` и «КОНТЕКСТ — передача в новый чат.md» описывают прежнюю версию
> («Балет при свечах», пролёт из кадров) и устарели.

## Сборка

```sh
npm ci
npm run build               # результат в dist/
ROBOTS=deny npm run build   # деплой-архив: robots.txt с Disallow: /
npm run check               # содержание, контраст токенов, бюджет передачи
npm run serve               # локальный просмотр dist/ на :4173
npm run preview             # .build/preview.html — вся страница одним файлом (для артефакта)
```

Заливаем **содержимое** `dist/`, включая `.htaccess`. Внешних запросов нет.

## Устройство

* `src/content.js` — все тексты; `src/icons.js` — собственный набор пиктограмм
  (24 × 24, линия 1.5 px, `currentColor`); `scripts/render.mjs` — разметка и
  типографика; `scripts/build.mjs` — сборка с хэшами в именах.
* `src/css/` — `tokens`, `base`, `sections` (шапка, первый экран), `blocks`
  (блоки 2–12, плеер), `motion` (всё движение; под `prefers-reduced-motion`).
* `src/js/` склеивается `scripts/bundle-js.mjs` в **один классический скрипт**:
  `mode` (режим `<html data-mode>`, `?mode=`, localStorage), `scene` (смена
  режима), `header`, `components` (вкладки, аккордеоны), `reveal` (появление,
  счётчики), `scrollfx` (параллакс, линия глав), `decor`, `media`, `player`.
* Шрифты Prata и Golos Text — из `@fontsource`, самохостинг.

## Режимы {НЕ}

Одно состояние на `<html data-mode="all|chamber|big">`; разделы скрываются
атрибутом `hidden`. Три входа: {НЕ} в знаке, большой переключатель на первом
экране, мини-переключатель в шапке (на телефоне — в меню).
`?mode=chamber|big|all` открывает нужный режим, выбор хранится в localStorage.

## Занавес первого экрана: два варианта

* **a** (по умолчанию) — граница едет через `flex-basis` + `opacity`, 1100 мс.
* **b** — обе половины стопкой, граница едет через `clip-path`, открывшееся
  видео «оседает» 1,06 → 1.

Посмотреть: `?hero=a` или `?hero=b` (выбор запоминается).

## Медиа без правки кода

Файлы кладём в `media/`, слоты описываем в [`media/media.json`](media/README.md).
Нет записи или файла — слот остаётся красивой заглушкой (свечение, зерно, подпись).
Типы: `bg` (фоновое видео), `inline` (видеовставка с плеером), `img` (фото,
webp + jpg, три размера), QR строятся при сборке из URL.

## Движение

Анимируются `transform`, `opacity`, `clip-path`, `filter`, `stroke-dashoffset`
(и высота аккордеона). Без библиотек. При `prefers-reduced-motion: reduce`
ничего не движется, все состояния меняются мгновенно.
