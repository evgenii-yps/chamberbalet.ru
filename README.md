# chamberbalet.ru

Главная страница «Театр {НЕ} Камерного балета» с переключателем масштаба
(«Весь театр» / «Без {НЕ}» — камерный / «С {НЕ}» — большая сцена).
Задание — ТЗ v1.0 от 29.10.2026; тексты — его приложение А, они лежат в
[`src/content.js`](src/content.js) и больше нигде.

> `SPEC.md` и «КОНТЕКСТ — передача в новый чат.md» описывают прежнюю версию
> («Балет при свечах», пролёт из кадров) и устарели.

## Сборка

```sh
npm ci
npm run build            # результат в dist/
ROBOTS=deny npm run build   # деплой-архив: robots.txt с Disallow: /
npm run check            # содержание, контраст токенов, бюджет передачи
npm run serve            # локальный просмотр dist/ на :4173
```

Заливаем **содержимое** `dist/`, включая `.htaccess`. Внешних запросов нет.

## Устройство

* `src/content.js` — все тексты; `scripts/render.mjs` — разметка и типографика
  (неразрывные пробелы, `{НЕ}`); `scripts/build.mjs` — сборка с хэшами в именах.
* `src/css/` — `tokens.css`, `base.css`, `sections.css`, `motion.css`.
* `src/js/` — `mode.js` (режим `<html data-mode>`, URL `?mode=`, localStorage),
  `scene.js` (занавес через View Transitions, откат — кроссфейд),
  `components.js` (вкладки, «показать всех», шапка), `micro.js` (аккордеоны,
  счётчики, появление), `decor.js` (подсказка, курсор-свет, пауза вне экрана).
* Шрифты Prata и Golos Text — из `@fontsource`, самохостинг.

## Слоты медиа

Положите в `media/` (нет файла — нет узла, декор остаётся):
`hero-chamber.(mp4|webm|jpg)`, `hero-big.(mp4|webm|jpg)`, `olesya.jpg`.
После добавления фото — проверить контраст подписи первого экрана.

## Режимы и движение

Режим — одно состояние; разделы скрываются атрибутом `hidden`. Анимации только
`transform`/`opacity`/`clip-path`/`filter` (кроме высоты аккордеона), всё
отключается при `prefers-reduced-motion: reduce`.
